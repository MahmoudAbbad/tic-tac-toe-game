# Tic-Tac-Toe Game 🎮

A simple Tic-Tac-Toe game built using Windows Forms in C#.
This project was developed to practice building desktop applications, writing clean code, and applying Object-Oriented Programming (OOP) concepts.

---

## 🛠️ Technologies Used

* C#
* Windows Forms (.NET)

---

## 🎯 Features

* Player vs Player mode
* Clear win and draw detection system
* Game restart functionality
* Simple and user-friendly interface

---

## 🧠 Concepts Applied

* Object-Oriented Programming (OOP)
* Event-driven programming
* Clean code practices
* GUI development using Windows Forms

---

## ▶️ How to Run

1. Open the project in Visual Studio
2. Build the solution
3. Run the application

---

## 📌 Project Purpose

This project was created as a learning exercise to improve skills in:

* Windows Forms development
* Structuring clean and maintainable code
* Applying OOP principles in real projects
